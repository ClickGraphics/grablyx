# GRABLYX

GRABLYX is a zero-budget-first multimedia web project focused on a fast, simple experience for working with publicly accessible media links.

## Project status

MVP under active development.

## Principles

- Fast, mobile-first UX
- Best available source quality
- Modular platform architecture
- SEO-ready from the start
- Zero-cost-first infrastructure
- No bypassing DRM, authentication, paywalls, or access controls
